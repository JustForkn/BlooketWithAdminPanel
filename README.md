# Blooket-style Game Hub

GitHub Pages-ready single-page project based on the uploaded HTML.

- Local `favicon.svg` so the favicon works without relying on an external favicon URL.
- Expanded Play screen with the current Blooket game-mode catalog, including seasonal modes.
- Per-mode admin panel for every current mode.
- Click the logo 13 times quickly to unlock the Game Mode Admin Hub.
- Per-mode admin controls: bot count, time per question, score multiplier, auto-correct, and infinite time.
- Existing collection, packs, dashboard, stats, settings, and quiz systems are retained.

Upload the files to the repository root and enable GitHub Pages. Everything is client-side and saves locally in the browser.
